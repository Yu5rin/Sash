# 変更履歴

## 0.3.1

業務で使うアイコンを増やし、日本語の言葉で引けるようにして、アイコンの色の既定の配色（パレット）を増やした。

### 追加
- **業務向けのアイコンを 276 種足した（合計 約 8,300 種）。** Lucide（ISC License）から、ものづくり・物流・営業・事務・開発・品質向けに 187 種を選んで取り込み、どのアイコン集にもなかったもの 89 種（エレベーター・エスカレーター・旋盤・金型・溶接・パレット・見積書・段取り替え・外注・内製・非常停止・表示灯・ヒヤリハット・ビジネスマン・回覧・戸開／戸閉・階数表示・閉じ込め・動く歩道・手すり・足元注意 など）を自分で描いた。アイコン集のダイアログの出どころに［Lucide］［Sash］を足し、カテゴリ「ものづくり・工場」を足した
- **営業・設計・工作・出荷・開発・検討・部品・製品・エレベーター・エスカレーター・町工場・ビジネスマンの言葉で、アイコンを引けるようにした。** 概念の辞書を 418 から 685 に、見出しを 4,397 から 6,941（重なりを除いた数）に拡充（出庫・昇降機・段取り替え・山積み・アンドン・外注・内製・治具・研削・板金・鋳造・めっき・5S・ヒヤリハット・歩留まり・稟議・予実・Web会議・戸開・戸閉・閉じ込め・階数表示・動く歩道・手すり・足元注意 ほか、漢字・ひらがな・カタカナ・英語の言い換えと表記ゆれ）。「ビル」（建物）と「ビール」（飲み物）を区別して探す
- **アイコンの色の既定の配色を 6 色から 75 色に増やした。** 色相ごとの 13 列 × 濃さ 5 段と Office の標準の色 10 色。色の名前（読み上げ・英語の訳つき）、キーボード操作（矢印・Home / End）、最近使った色、#RRGGBB の入力を足した。アイコン集のダイアログは右の欄にパレットを常に出し、アイコンエディタの色の入力（単色・色の置き換え・バッジ）には［▾］でパレットを開ける。Office の黒・白のテーマで背景に沈む色には印とメモを出す（判定は配布前チェックと同じ基準）

### 変更
- サードパーティのライセンスの一覧に、Lucide（ISC と Feather 由来の MIT）と Sash のオリジナルのアイコンを足した
- アイコン集のダイアログは、縦も少し広くとる（パレットが収まるように）
- 英字のあいだの `&`（R&D・Q&A）は 1 語として検索する

### 修正
- アイコン集のダイアログのプレビューが、中身が多いと潰れて見えなくなる作りだったのを、縮めずにスクロールさせるようにした
- Tabler の `nut`（六角ナット）が「食べ物」のカテゴリに入っていたのを、「ものづくり・工場」に直した
- 「エレベーター」で探すと階段（stairs）が先頭に出ていたのを、エレベーターが先頭に出るようにした（辞書の見出しの整理）

## 0.3.0

既存のマクロの割り当て・未保存の編集の復旧・別のブックからの取り込みと比較・ほかで書き換えられたファイルの検知・配布前チェックの追加項目の 5 件。仕様は [SPEC §23](SPEC.md)。Excel・VBA・ファイルの実機（Windows）での挙動は、まだ確かめていない（SPEC §23.7）。

### 追加
- **既存のマクロをボタンに割り当てる。** インスペクタの onAction の［マクロを選ぶ…］、ツール → VBA の［既存のマクロを割り当てる…］から、ブックの VBA にある引数なしの Sub を選ぶと、それを呼ぶだけの Sub（リボンの引数を受け取る形）を作って挿入し、割り当てる。Private・引数あり・Function・標準モジュール以外の Sub は理由つきで選べない。名前が重なれば番号を付ける。コールバック一覧の「引数が不一致」にも［呼び出し用の Sub を作る］を追加した
- **未保存の編集の自動退避と復旧。** 編集中の XML と画像の差分を、変更の 3 秒後（続けて編集しても 15 秒以内）に %AppData%\Sash\recovery へ退避し、保存・閉じるで消す。次にそのブックを開いたとき、［復旧する］［差分を見る…］［捨てる］を選べる。ホームにも「復旧できる編集があります」を出す。退避の失敗では編集を止めず、30 日より古い退避は掃除する
- **別のブックのリボンを取り込む・見比べる。** ファイル → ［別のブックから取り込む…］で、別のブック（.xlsm / .xlam など）・customUI の .xml・.sash.json から、タブ・グループ・コンテキストタブ・右クリックメニュー・Backstage を選んで画像ごと取り込む。id の重なりは振り直し、使うコールバック（VBA は運ばれない）の Sub の雛形を案内する。ツール → ［別のブックと比べる…］、ファイル → ［customUI の XML を書き出す…］も追加した
- **ほかで書き換えられたファイルの検知。** 保存・反映の前と、窓に戻ったとき、開いたあとにほかでリボンが変わっていないかを調べる。Excel の保存し直しで誤って知らせないよう、バイト列ではなく、XML を正規化した中身と画像で比べる。違えば、上書き・読み込み直し・差分の確認を選べる。設定でオフにできる
- **配布前チェックの追加項目。** ほかのアドインと重なりやすい名前（id・タブ名・コールバック名）、onLoad と Invalidate の入れ忘れ、暗いテーマ（白いテーマ）で沈むアイコン、大きすぎる画像、配布先でマクロがブロックされることの案内（インターネットから取得した印の検出つき）
- 設定に「編集の自動退避」と「外部での変更の検知」を追加した

### 見直しでの修正（0.3.0 の中）
- 別のブックから取り込むとき、id を振り直したら、命名規則で付けたコールバック名も付け直す（取り込んだボタンが既存の Sub を共有して、既存のマクロが動かないように）。規則外の名前が取り込み先と重なるときは警告する。idQ などの接頭辞の宣言を取り込み先に足し、宣言のない接頭辞は Lint のエラーにする。重なる keytip は外し、同じ組み込みへの合流で捨てた属性を知らせる
- 同じブックを開き直したとき、捨てたはずの退避の復旧を聞かないようにした。窓に戻ったときの黙った読み直しの前に入力中の欄を確定し、編集のない反映では「ほかでの変更」の基準を動かさない
- 2 つの Sash で同じブックを開いても、退避を取り合わない（退避のファイル名にプロセス ID を入れた）。落ちた Sash の退避は復旧できる
- マクロの割り当て中に文書が変わっても、別の要素に付けない
- 保存しないで終わる・言語を切り替える・更新するときも退避を消す。復旧後の［元に戻す］はすべてのパーツを戻す。保存後の照合値が読めなくても「保存できませんでした」と出さない
- 画像の色を調べられなかったときに「調べています…」が残らないようにし、覚えに上限を付けた。onLoad の判定の誤りを直した。退避は変わった画像だけを送る。つながらないネットワーク パスでも、復旧の一覧は 2 秒で打ち切る
- 窓に戻ったときの黙った読み直しで、読み込み中に入った編集を上書きしないようにした。落ちた Sash の退避が、プロセス ID の使い回しで隠れ続けないよう、開始時刻と名前も見る。退避に前回の画像を引き継げないときは、書き込みを失敗にして画像を全部送り直す。画像の色の覚えの固定の上限をやめた。共有の命名規則どおりの名前は、重なりの警告から外した。keytip の重なりは、タブどうし・同じタブの中どうしで比べる

### 変更
- 差分ダイアログを、左右の XML を渡せる形にした（保存済みとの差分・復旧する内容との差分・ほかで変更された内容との差分・別のブックとの差分で共用）
- ボタンが多いダイアログの足もとは、収まらなければ折り返す
- 設定ファイルに `autoRecovery` と `detectExternalChanges` を足した。ホストの要求に `recovery.*`・`file.fingerprint`・`file.read` を足した

## 0.2.0

製品版に向けた総点検（高・中の指摘 31 件）の対応。画面が窓からはみ出す・通知がボタンに重なる・製品版で右クリックが効かない、などの不具合の修正と、メニューと見た目の整理。

### 修正
- **仕切りを動かすと、画面が窓からはみ出していたのを直した。** 保存した大きさは変えず、表示する大きさだけを窓に収める（窓を戻せば元の大きさに戻る）。窓の大きさを変えたときも丸め直す。ペインには下限（左 200・インスペクタ 260・下部 96px）を設けた
- **通知がダイアログの［閉じる］などに重なって押せなかったのを直した。** ダイアログを開いている間は、通知を右上に出す
- **製品版で、入力欄と XML エディタの右クリックに何も出なかったのを直した。** 入力欄には切り取り・コピー・貼り付け・すべて選択を、XML エディタには Monaco のメニューを出す
- **配布前チェックが、Excel でリボンが出なくなるエラー（id の重複など）を「警告」の色で見せていたのを直した。** エラーは赤で、見出しは「このまま配ると、Excel でリボンが表示されません（エラー n 件）」。エラーと警告の節も分けた
- **想定外の例外が黙って消えていたのを直した。** 通知を出し、ログ（`%AppData%\Sash\logs\app.log`）にも残す。起動の最初の問い合わせが失敗しても、既定の設定で画面を動かす
- XML エディタの検索などが英語のままだったのを日本語にした
- 「最後の正しい状態に戻す」のあと、選択が customUI に飛ぶのを直した。確認の文も実際の動き（元に戻せる）に合わせた
- ダイアログ左下のボタン（［削除］［VBA を再読み込み］）の文字が上にずれていたのを直した（CSS のクラスの衝突）
- ウィンドウが毎回 1440×900 で開き、位置と大きさを覚えなかったのを直した。位置・大きさ・最大化を覚え、小さな画面（幅 1440 未満）では最大化で開く
- Ctrl+ホイールで画面が拡大され、戻せなくなる事故を止めた
- ファイルの読み書き・バックアップの復元・アイコンライブラリが、ウィンドウを「応答なし」にしないよう、UI スレッドの外で動くようにした
- 壊れたファイルを開いたとき、.NET の英語の文を出さず、分かる言葉で知らせる。想定外の失敗は「予期しないエラーが起きました（詳しくはログ）」にした
- Excel が応答しないとき、反映が 15 秒を超えたら理由の心当たりを知らせ、［待つのをやめる］を選べるようにした（VBA の読み書きは通知のみ）
- インスペクタを狭めると切り替えが重なって読めなかったのを直した（下限 260px、狭いときはラベルの下に値を置く）
- コマンドパレットが、いま使えないコマンドを隠していたのを直した（薄く出して理由を添える）

### 追加・変更
- メニューの項目にアクセスキーを付けた（Alt+F → S で保存）。ファイルと編集の主な項目から
- 表示メニューを、働きごとの入れ物（ペインへ移る・キャンバスの表示・下部パネルのタブなど）にまとめた。ツールの VBA 項目も 1 つにまとめた
- ファイルに「Excel で開いているブック」・Ctrl+N・Alt+F4 の表示を足し、サンプルはヘルプへ移した。編集に「名前を変える（F2）」を足し、削除の表示を `Del` に統一した。ヘルプに「使い方（README）」「ログのフォルダー」を足した
- サンプルでは保存・反映を無効にして理由を出す。Excel がないときは反映ボタンを「ファイルに書き込む」にし、ファイル名の右に Excel とのつながりの印を出す
- 問題がないあいだは、下部パネルを帯に畳む（問題が出たら開く。自分で開閉・ドラッグしたあとは自動にしない）
- ホームを整理した（アイコン、［サンプルを開いて試す］、1 行のドロップの案内、右に Excel で開いているブック）
- ツリーの「ribbon」と「tabs」を 1 行にまとめ、ID を右寄せにした
- Backstage・右クリックメニュー・自作のタブがないときの「空の状態」を、1 つの部品に揃えた
- アイコンエディタの並びを整理した（プレビューを上に、画像を選ぶボタンを 2 列に、見出し＋区切り線に。読み込むまで設定は薄く）
- 表記をそろえた（英字と日本語の間の半角空白、数の付け方、元に戻すの名前、「右クリックメニュー」）
- デザインを改めた：ボタン・入力欄の枠を薄く（入力欄は下の線だけ濃く）、スクロールバーを細く、選択の青と主操作の緑の使い分け、文字・角丸・影のトークンを整理、XML エディタの地をペインに合わせた

### 見直しと「低」の指摘への対応
- 入力欄の右クリック［貼り付け］で貼った値が、インスペクタで捨てられていたのを直した（`change` が出なかった）。数値・メールの欄で例外になるのも直した
- 更新の確認先・レシピの id・アイコンの id などの不正を、「予期しないエラー」ではなく、分かる言葉で知らせる
- 窓に戻るたびに Excel へ問い合わせて、F5 が待たされることがあったのを直した（重ねない・30 秒に 1 回・保存や反映の最中は送らない）
- ウィンドウの位置：タイトルバーが画面の外に出る位置・画面より大きな大きさで開かないようにし、最小化したまま閉じても最大化を覚える。旧版で保存した細すぎるペインは、畳むか下限に戻す
- 待つのをやめた反映で「Excel 側に未保存の変更」が届いたとき、成功の通知にしないで、やり直しを案内する
- マウスで開いたメニューでもアクセスキーが効く。表示・挿入・ツール・ヘルプの項目にもアクセスキーを付けた
- F6 の順を画面の並びに、ハイコントラストの指定、削除の通知を絞る（1 つのコントロールは出さない）、ホームのドロップの案内を押せるように、「?」の案内をキーボードで読めるように、何も選んでいないインスペクタの案内、アイコンの候補を 1 つの Tab 停止に、右クリックメニューの呼び方の統一、差分・ショートカット一覧・検索欄の整理、ツールバーに［配布前チェック］、VBA の照合の印、英語の大文字の統一、ほか
- 見送り：W-6・W-7（Excel 実機が要る）、W-2 の拡大メニュー、S-7（理由は docs/SPEC.md §22.11）

## 0.1.2

分割ボタンのアイコンとラベルを、インスペクタなどから設定できるようにした。あわせて、アイコンまわりの総点検で見つけた不足を直した。

### 修正
- **分割ボタンを選んでも、アイコンとラベルを設定できなかったのを直した。** customUI の決まりで、分割ボタン自身には label や image を付けられず、中の先頭のボタン（button / toggleButton）が持つ。分割ボタンのインスペクタの先頭に「ラベルとアイコン」の区画を出し、中のボタンに書き込むようにした（「中のボタン（btnXXX）に設定されます」と表示し、中のボタンへ移るリンクも置いた）。アイコンエディタ・ライブラリ・画像のドロップ・コマンド・imageMso カタログ・まとめて変更でも、分割ボタンが選ばれていれば中のボタンに設定する。元に戻すは 1 回
- Backstage の項目（dropDown・comboBox の item、radioButton）に image / imageMso を付けられると誤って扱っていたのを直した（スキーマでは持てない。getLabel は持てるので足した）。**以前の版でこれらに image / imageMso を付けて作ったファイルは、Lint のエラーになる。** メッセージの案内どおり、XML エディタで image / imageMso を消してください
- キャンバスで、editBox・comboBox・dropDown と Backstage のボタンの getImage（VBA で返すアイコン）の印が出ていなかったのを直した

### 追加
- 分割ボタンに label / imageMso などを書いたときの Lint のエラーに、「中の button / toggleButton に付けます」と直し方を添えた
- キャンバスのメニュー・ギャラリーなどのポップアップに、項目のアイコンを描くようにした。分割ボタンの項目は、中のボタンのラベルとアイコンで出す
- ツリーの分割ボタンの行に、中のボタンのラベルを出す
- 分割ボタンの区画に、中のボタンのヒント（screentip / supertip）と、中のボタンについての Lint の指摘も出す。キャンバスの名前の直接編集（F2）と ID の提案も、分割ボタンでは中のボタンのラベルを使う
- Backstage の hyperlink にアイコンを描くようにした

## 0.1.1

古い WebView2 ランタイムで画面の背景色・枠線が消える不具合の修正。

### 修正
- **古い WebView2 ランタイム（Chromium 123 未満）で、背景色と枠線がすべて消えて透明になる不具合を直した。** 色の定義に使っていた `light-dark()` などが古い版では無効になるため。CSS をビルド時に lightningcss で Chromium 109 以上でも動く形へ変換し、`color-mix()` は半透明の色のトークンに置き換えた

### 追加
- 起動時に WebView2 ランタイムの版をログ（`%AppData%\Sash\logs\app.log`）に記録する。版が Chromium 109 未満のときは、画面が正しく表示されないことがある旨と、ランタイムの更新のお願いを一度だけ知らせる
- 「バージョン情報」に WebView2 ランタイムの版を表示する

## 0.1.0

最初のリリース。Excel のマクロブックとアドインのリボン（customUI）を、見たまま作って直せるエディタ。

### 追加
- **キャンバス・ツリー・XML エディタの三面同期。** どこで編集しても一つの履歴で元に戻せる。組み込みタブ・グループはグレーで示し、自分で足した部分だけを編集できる
- **インスペクタと検証。** 要素ごとに使える属性だけを出し、入力中に構造・値・id の重複・画像の参照・keytip の重複などを検証する
- **Excel へのワンクリック反映（F5）。** 開いているブックを保存・クローズ・書き込み・再オープンし、作ったタブを表示する。アドイン（xlam）は読み込み直す
- **VBA のコールバック。** XML と VBA の Sub を突き合わせ、未実装の Sub を正しい引数で生成・挿入する。名前を変えたときは VBA 側の宣言も変えられる
- **アイコンの作成。** 画像・ICO・SVG・EXE / DLL・組み込みアイコン・クリップボードから、リボン用の PNG を作って設定する。色・形・バッジなどの加工と、アイコンライブラリ（共有フォルダ対応）
- **カタログとレシピ。** idMso / imageMso のあいまい検索、よく使う構成の XML と VBA のセットでの挿入、コマンドパレット（Ctrl+K）
- **コンテキストメニューと Backstage の編集**、保存済みとの差分表示、`.sash.json` での書き出し・読み込み、英語 UI
